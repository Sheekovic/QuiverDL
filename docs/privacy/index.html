Privacy policy

Your downloads are your business.

QuiverDL does not operate an account service and does not collect analytics, advertising identifiers, telemetry, browsing history, or download activity.

Effective: August 19, 2026

On this page Scope Data stored locally Network requests Browser companions Website and GitHub Sharing and retention Your choices Changes Contact

1. Scope

This policy covers the official QuiverDL desktop application, its optional Chromium and Firefox browser companions, the native-messaging host, and this project website. Forks and third-party builds may behave differently; their maintainers are responsible for describing their own practices.

2. Data stored locally

QuiverDL stores the information needed to manage downloads on your device. Depending on how you use it, that may include source URLs, destination paths, filenames, transfer progress, server validators, retry state, speed settings, interface preferences, browser-pairing information, and resumable partial files.

This information is used only to provide the requested functionality. The QuiverDL project does not receive it. You can remove queue entries and downloaded or partial files using the application and your operating system.

3. Network requests

When you start or resume a download, QuiverDL connects directly to the address you supplied and to any redirects that address returns. Those servers and your network provider can observe ordinary connection information such as your IP address, request time, and the requested resource. Their privacy practices are outside QuiverDL's control.

QuiverDL does not intentionally send download details to the project maintainers or to an analytics service. Update checking is not currently implemented. If it is added later, its behavior will be documented before release.

4. Browser companions

Browser integration is optional. Manual capture is the default, and automatic interception is disabled until you enable it. Matching decisions happen locally. The companions do not intentionally collect or transmit cookies, authorization headers, page contents, browsing history, or telemetry.

A captured download URL is sent through an authenticated local native-messaging channel to the QuiverDL application so it can queue the download. URLs can contain private tokens, so avoid posting application logs or queue data publicly.

5. Website and GitHub

This is a static GitHub Pages website. It contains no QuiverDL analytics, tracking pixels, advertising, cookies, contact forms, or external fonts. GitHub hosts the site and may process technical information such as IP addresses and request logs under the GitHub Privacy Statement.

If you use the color-theme control, the site stores only your light or dark theme preference in your browser's local storage. It is never transmitted to the QuiverDL project and can be removed through your browser settings.

If you open an issue, discussion, pull request, or other contribution on GitHub, the content and account information you provide are processed and displayed by GitHub. Never include private download URLs, credentials, cookies, or personal files in a public report.

6. Sharing and retention

Because the QuiverDL project does not collect application data, it does not sell or share that data and has no central copy to retain. Information stored locally remains until you remove it or your operating system does. Information submitted to GitHub is retained according to GitHub's policies and the repository's moderation needs.

7. Your choices

  • Use QuiverDL without creating an account.
  • Leave browser interception disabled and send downloads manually.
  • Review the complete source code and build the application yourself.
  • Delete local queue entries, settings, partial files, and completed files.
  • Uninstall the browser companions or desktop application at any time.

8. Changes to this policy

Material changes will be committed publicly to the QuiverDL repository and the effective date above will be updated. The repository history provides an auditable record of every version.

9. Contact

For privacy questions, open a GitHub Discussion. For a sensitive security or privacy issue, follow the private reporting instructions in the Security Policy.
