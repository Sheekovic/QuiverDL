# QuiverDL Support

QuiverDL is early-stage software and does not yet have stable end-user releases.

## Questions and ideas

Use [GitHub Discussions](https://github.com/Sheekovic/QuiverDL/discussions) for setup questions,
design ideas, and general conversation. Discussions help other community members find and improve
answers over time.

## Bugs

Before reporting a bug:

1. Search existing issues.
2. Reproduce it with the newest code from `main` when practical.
3. Remove private URLs, credentials, tokens, cookies, and personal filenames from logs.
4. Use the structured bug form and include your operating system and reproduction steps.

## Security vulnerabilities

Do not use Discussions or public issues for suspected vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.
