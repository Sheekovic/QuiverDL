# Project Governance

QuiverDL is currently maintained by [Sheekovic](https://github.com/Sheekovic).

Project direction is discussed openly in issues, Discussions, and pull requests. Maintainers are
responsible for roadmap decisions, releases, moderation, security response, and merging changes.
Decisions prioritize download correctness, user safety, privacy, accessibility, and sustainable
maintenance.

Consistent contributors may be invited to triage issues or review pull requests as the community
grows. Expanded responsibility is based on constructive participation, technical judgment, and
alignment with the Code of Conduct—not only the number of commits.
